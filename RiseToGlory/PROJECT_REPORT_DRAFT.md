# Rise to Glory: Interactive Football Career Simulation

## Introduction

Rise to Glory is an interactive prototype developed in Ren'Py. The system places the user in the role of a young football player who must make decisions about position, training effort, match strategy, teamwork, transfer opportunities, and pressure management.

## Problem Background

Young athletes often imagine success as talent alone, but real sport performance depends on discipline, feedback, teamwork, social pressure, and decision-making. This prototype turns those issues into an interactive story so users can experience consequences instead of only reading about them.

## Target Users

The target users are students, young athletes, and casual players aged 13 and above who can understand simple choice-based interaction. They need clear instructions, fast feedback, visible progress, and meaningful outcomes.

## Objectives

1. Create a working Ren'Py prototype with clear user-system interaction.
2. Show how choices affect skill, confidence, coach opinion, reputation, teamwork, pressure, and career outcome.
3. Support emotional engagement through characters, match pressure, and social consequences.
4. Demonstrate usability principles such as feedback, error recovery, consistency, and learnability.
5. Provide an evaluation plan for improving the prototype after user testing.

## Interaction System Design

Input: The user enters a player name and chooses actions from menus.

Output: The system responds through dialogue, background changes, stat feedback, notifications, and final career outcomes.

Interface: The prototype uses a custom main menu, act cards, stadium backgrounds, decision menus, and a live performance dashboard.

Feedback: Every major choice updates visible stats or gives narrative feedback. The final report explains why the user achieved a specific ending.

## Development Methodology

The project follows an iterative prototyping method. This is suitable because Ren'Py allows fast testing of screens, dialogue, branching choices, and feedback. Compared with a fully planned waterfall method, iterative prototyping is better for interaction design because user experience can be improved after each test.

## Cognitive Design Considerations

The interface reduces memory load by showing the player's current stats on screen. Choices are written in simple language and usually explain the risk or intention. The system gives immediate feedback after important actions, so users can learn the relationship between decisions and outcomes.

## Social Design Considerations

The story includes a coach, teammate, scout, fans, and club loyalty. These characters make the prototype feel social instead of mechanical. Users do not only chase points; they must manage trust, reputation, teamwork, and pressure.

## Evaluation Method

Suggested evaluation: task-based usability testing with a short questionnaire.

Test task: Ask users to play once and try to earn a professional contract. Then ask them to replay and improve their result.

Observation checklist:

1. Can the user start the game without help?
2. Does the user understand what each choice means?
3. Does the dashboard help the user understand progress?
4. Can the user recover from a poor choice by replaying?
5. Does the final outcome feel connected to earlier decisions?

Questionnaire items, rated 1 to 5:

1. The prototype was easy to learn.
2. The choices were clear.
3. The feedback helped me understand my progress.
4. The story was emotionally engaging.
5. I understood why I received my final ending.
6. I would replay the prototype to try another path.

## Findings and Discussion Template

After testing, summarize the average questionnaire score and the most common user comments. Discuss whether users understood the choices, whether the dashboard helped, and which parts caused confusion.

## Limitations

The current version uses generated background images and text-based characters. It does not yet include sound effects, music, animated character sprites, or a saved questionnaire screen.

## Future Improvements

Future versions can add football sound effects, character portraits, more match scenarios, accessibility options, and a built-in post-play questionnaire. More playtesting can also balance the scoring system so each career path feels fair.

## Rubric Mapping

Output: The system provides visual backgrounds, dialogue, stat feedback, notifications, and final outcome summaries.

Interaction flow: The user moves from introduction to position choice, training, first match, feedback, transfer decision, final match, and ending.

Evaluation: The project includes a task-based usability test and questionnaire plan.

Improvement: The ending report and this draft identify clear future upgrades.
